Política de Privacidad

Al invitar o usar RedBot, aceptas esta política. Explicamos exactamente qué hacemos con tus datos.

01 / Recopilación

Información recopilada

Registro del servidor

Cuando RedBot se agrega a un servidor, almacena el ID del servidor para propósitos de configuración.

Uso de comandos

Cuando ejecutas un comando, el bot procesa temporalmente:

  • ID del usuario
  • ID del servidor y del canal
  • Nombre del comando y sus parámetros

Esta información se usa únicamente para ejecutar la función solicitada.

Contenido de mensajes

RedBot NO lee ni almacena todos los mensajes del servidor. El contenido solo se procesa cuando el usuario explícitamente usa un comando.

02 / IA

Procesamiento de IA

Al usar el comando de IA, el contenido se transmite temporalmente a un proveedor externo.

  • El contexto se guarda en memoria y se descarta tras inactividad.
  • RedBot NO usa tu contenido para entrenar modelos propios.
  • Tu contenido no se vende. Puede transmitirse temporalmente a los proveedores necesarios para procesar la solicitud de IA.
03 / Almacenamiento

Almacenamiento de datos

  • No hay bases de datos permanentes de contenido de mensajes.
  • Los datos de configuración se almacenan en la base de datos principal.
  • Los datos en memoria se eliminan de forma automática.
04 / Compartición

Compartición de datos

RedBot no vende ni alquila datos. Cuando es necesario para prestar el servicio, determinados datos pueden transmitirse a:

  • API de Discord (requerida para funcionar).
  • Proveedores de infraestructura y procesamiento.
  • Autoridades si es requerido por la ley.
05 / Eliminación

Eliminación de datos

Los administradores pueden eliminar datos de configuración removiendo el bot del servidor.
